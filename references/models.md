# 模型：每档是哪个，开工时自己认

`SKILL.md` 和别的文件只说档：**最强、中档、便宜**，另有比最强还贵的**最贵**。**总控写死：Claude 用 Opus 5.5，思考强度超高**（Codex 用 Astra 6，超高）。这是作者实测的：又聪明又快；让总控自己挑「最强的」，可能挑到更贵的 Fable，或者没试过的型号。

别的档不写死：总控开工时从环境里认出来，写进项目卡。模型换代了，下次认到的就是新的。

## 每档怎么认

| 档 | 用在哪（见 `SKILL.md` 第三节） | 是哪个 |
| --- | --- | --- |
| 最强 | 总控；要判断边界、设计方案的线；调研现成项目、项目梳理；设计线；碰核心的审查、全仓体检 | **总控：Opus 5.5**（Codex 用 Astra 6）。线不能比总控高，所以最强档的线就跟总控一样 |
| 中档 | 照单执行的线；改了一般行为的审查；对稿 | 同一家、最新一代里比最强便宜一档、厂商说适合日常和照单任务的 |
| 便宜 | 只读的大范围查找（子 agent）；照单的小活 | 同一家、最新一代里最快最便宜的；没有就用中档 |
| 最贵 | 默认不用；真要用先问用户、说清为什么 | 同一家里比总控那档还贵的；没有就没有这一档 |

- 只认**最新一代**：同一条产品线有好几个版本的，取版本号最新的。
- 「最强」说的是总控这一档，不是价钱最高的那个；比它还贵的叫「最贵」，默认不用。
- 总控不是 Opus 5.5 + 超高的，开工对齐时请用户换（`templates/kickoff.md` 第 8 项）。用户不换，线就跟着总控现在的模型，不能比它高。

## 从哪认

按顺序，前面的有就不往后找：

1. **环境自己说的。** Claude Code 的系统提示里写着总控自己的型号和 id（「你用的模型是……，确切的 id 是……」），也列着这一家当前的模型和 id（「最新的 Claude 模型是……家族，模型 id……」）。Codex 看 `/model` 列出的模型和它们各自的说明。WorkBuddy 看它的模型选择里有哪些。
2. **开会话、开子 agent 的工具接受什么。** 比如 Claude Code 子 agent 的 `model` 只收 `opus`、`sonnet`、`haiku`、`fable` 这几个别名，别名本身就指向这一档最新的型号。
3. **还拿不准**（分不清哪个贵、哪个是新一代）：看一次厂商官方的模型页和价目页，认完写下依据。

不靠记忆认：总控记得的型号可能已经过时。

## 认完写下来

- 写进项目卡「用户定过的事」下面一行：`模型（<日期> 认，依据 <从哪读到的>）：总控 = Opus 5.5、超高，中档 = <型号 / id>，便宜 = <型号 / id>，最贵 = <型号，或没有>`。
- 每次开线前看一眼：环境列的和项目卡写的对不上（换代了，或用户换了总控），就照上面重认一遍，改项目卡，在下一条里程碑消息里说一句。
- `notes.md` 里每条线记的是开它时用的真实型号。

## 开线和子 agent 怎么写

- **最强档的线：不写模型**，它就跟总控一样。这样永远是总控现在用的那个，换代了也不用改。
- **中档、便宜档的线：** 写认出来的 id（Claude Code 桌面端 `start_session` 的 `model` 要 id；命令行 `--model` 可以写别名）。
- **子 agent：** 写别名（`sonnet`、`haiku`；最强档写 `opus` 或不写），别名会自己指向最新的。
- **自动压缩窗口**（`tools.md`「上下文」）按模型 id 设：写总控的 id 和中档的 id，都用这次认出来的。换代后 id 变了，设置要跟着改；那是用户级设置，改之前问用户。

## 思考强度

五档：低（low）、中（medium）、高（high）、超高（xhigh）、极高（max）。Claude Code 开线时写 `effort`，子 agent 在 frontmatter 写 `effort`；Codex 写 `model_reasoning_effort`，或 `/model --reasoning=<档>`。

| 谁 | 档 | 思考强度 |
| --- | --- | --- |
| 总控 | Opus 5.5（Codex 用 Astra 6） | 超高 |
| 要设计方案的线、设计线、调研和梳理 | 最强 | 高 |
| 照单执行的线、审查、对稿、查找 | 中档或便宜 | 中 |

极高基本不用：慢、费额度，还爱自己扩大范围。线的思考强度也不能高于总控，所以总控开超高，正好盖得住。新模型的思考强度档位名字变了，照它自己的说明对上这五档。

只是让你看认完长什么样，别照抄，开工时照上面重新认。
